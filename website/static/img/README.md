# Images

## Logo

- `wordmark-dark.svg` and `wordmark-light.svg` are the logo for dark and light backgrounds: two linked gold rings, "chainmail" in DM Mono 500 and a block cursor. The letters are outlined, so the files need no font. The cursor blinks, and stays still for visitors who ask for reduced motion.
- `favicon.svg` is the rings on a navy rounded square. `favicon.ico`, `favicon-192.png` and `apple-touch-icon.png` are the same mark at icon sizes. The Apple icon is square, because iOS rounds the corners itself.

The landing page keeps its own copies in `site/public/img/`.

## Gopher

The chainmail gopher was made for chainmail from the Go gopher. It is a gopher in a mail coif and hauberk, holding a navy shield that carries a gold envelope.

- `mascot.png` is the full figure on a transparent background. The repository README uses it.
- `social-card.png` is the 1200x630 preview image that link previews show, with the wordmark at the top left.

The Go gopher was designed by Renée French and is licensed under CC BY 4.0. The chainmail gopher is a derivative work under the same license.
