# Images

The chainmail gopher in these files was made for chainmail from the Go gopher.
It is a gopher in a mail coif and hauberk, with a quill-tipped sword and a shield that carries an envelope.

- `mascot.png` is the badge on a transparent background. The home page and the repository README use it.
- `logo.png` is the badge at 128 pixels high, for the navigation bar.
- `favicon.ico` and `favicon-192.png` are the gopher's head, cropped from the badge.
- `social-card.png` is the 1200x630 preview image that link previews show.

The Go gopher was designed by Renée French and is licensed under CC BY 4.0. The chainmail gopher is a derivative work under the same license.
