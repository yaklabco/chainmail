These CSS, JavaScript, JSON and SVG files are the page kit the landing page runs on, vendored from https://github.com/Leonxlnx/taste-skill under the MIT licence in `LICENSE`. They are served as plain static files because the kit loads its own modules, effects and moments at run time by URL. Only the files the page loads are kept, and they are unchanged apart from removed comments that described the upstream project's own tooling.
